# Application source

This capstone extends my [Typeahead application](https://github.com/vimalyad/typeahead),
starting from commit `fcf6e9c42084cb049353726e003441e7d6cf0827`.

The original React search interface, Java ingestion and suggestion services, PostgreSQL
schema, trie ranking, consistent-hash cache routing and Kafka aggregation are reused.
The capstone adds query management, endpoint tests, reproducible containers, gated delivery,
Kubernetes/Helm, cloud infrastructure, monitoring, GitOps and troubleshooting exercises.
Java/JUnit/Flyway are the approved equivalents of the reference's Python/Pytest/Alembic stack.
Original performance reports and screenshots are not evidence for this capstone.
